# Dongwook Choi

Personal academic website for Dongwook Choi, built with Jekyll and adapted from the [Bay](https://github.com/eliottvincent/bay) theme.

## Local Development

```sh
bundle install
bundle exec jekyll serve
```

The site is deployed through GitHub Actions using Ruby 3.3.

## Backup

The previous site snapshot is kept locally at `backup_before_bay_20260606/` and is excluded from the generated site and Git tracking.
